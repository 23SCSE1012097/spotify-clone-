# Spotify Clone 🎵

A responsive Spotify Clone web application built using HTML, CSS, and JavaScript.  
This project replicates the basic UI and music player functionality of Spotify.

---

## 🚀 Features

- Play and pause songs
- Next and previous song controls
- Responsive design
- Spotify-inspired UI
- Playlist section
- Progress bar for songs

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
